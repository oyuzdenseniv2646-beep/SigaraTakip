SigaraTakip
===========

A lightweight Android application for tracking daily cigarette consumption.

SigaraTakip allows users to quickly record cigarettes from both the application and a persistent notification. The application stores daily records locally and automatically starts a new counter when the date changes.

Features
--------

- Daily cigarette tracking
- Quick logging from the notification panel
- Simple Android interface
- Automatic daily counter
- Local data storage
- Works offline
- No account required
- Lightweight and fast

Building
--------

The project can be built directly on Android using Termux.

Requirements:

- Java / OpenJDK
- AAPT2
- D8
- APKSigner
- Android SDK platform files

After cloning the repository:

    chmod +x build.sh
    ./build.sh
